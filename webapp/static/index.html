METAL DAILY とは

価格把握から換算・通知までを一体化した監視ビュー

MetalpriceAPIとGoogle News（RSS）から取得した金・銀・プラチナ価格をJST 00:00基準で更新。予測・換算・履歴確認を1画面で完結できます。

更新頻度とソース

毎日00:00（JST）に価格を更新。USD/JPYと関連ニュースを加味して1週間予測を再計算します。

通知と計算ツール

毎日11:00（JST）にブラウザ通知を配信。重量と純度を入力するだけで最新価格から即座に円換算できます。

対象金属Gold（金） / Silver（銀） / Platinum（プラチナ）
提供機能価格推移チャート / 1週間予測 / 純度計算 / Push通知

FAQ

運用と使い方に関するよくある質問

MetalpriceAPIとGoogle News（RSS）を参照し、価格データとニュースデータを突合して表示しています。

毎日11:00（JST）にブラウザ通知を配信。未設定の場合は「Push通知を有効化」ボタンから登録できます。

表示期間セレクタで30日、90日、180日、365日の履歴を切り替えて確認できます。

金・銀・プラチナの3種に対応しており、純度係数を掛け合わせた概算価格を計算できます。
