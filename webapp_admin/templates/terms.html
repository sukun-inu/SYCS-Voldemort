{{ icon('robot') }}サービスの概要

本 Bot は Discord 上で以下の機能を提供します。

  • 情報提供 — 貴金属価格の表示、サーバー情報・ユーザー情報の確認、Google News フィードの自動投稿
  • DJAudio-DL — YouTube・SoundCloud などの対応サービスから音声を抽出（yt-dlp を使用）し、期限付きダウンロードリンクをサーバー内に提供
  • AI 会話 — OpenAI / Groq API を用いたヴォルデモート卿キャラクターによる会話
  • 通知・自動化 — 地震アラート、VC 通知、ウェルカム／グッバイ、スティッキーメッセージ、リアクションロール
  • セキュリティ検知 — スパム・Unicode トリック・VirusTotal によるURL/添付スキャン・AI モデレーション・VC レイド検知
  • ユーザー状態監査 — 参加/退出、BAN/KICK、ロール変更など運用上重要なイベントの記録と可視化
  • Web 管理画面 — Discord OAuth2 で認証した管理者が各機能の設定を管理できるダッシュボード

VC録音機能の利用

VC録音機能は、議事録として記録を残す用途、および法令に基づき政府機関・法的機関へ提供する必要が生じた場合の用途を想定しています。 本サービスの運営者は、政府機関への提供が必要な場合を除き、録音データを一切使用いたしません。

本機能を各サーバーでどのように使用するかは、その運用者が適用される法令に則って判断し、実施してください。 音声は個人情報保護法上の個人情報に該当し得ます。録音を行う運用者には、参加者への事前の周知、必要な同意の取得、 利用目的の特定と目的外利用の禁止、安全管理措置、保存期間の適切な設定といった義務が生じ得ます。 本サービスは録音の手段を提供するものであり、個々の運用が適法であることを保証するものではありません。

なお、本 Bot は録音開始時に対象チャンネルへ録音中である旨を必ず通知し、参加者は /record exclude により自身を録音対象から除外できます。これらの機能を無効化することはできません。
