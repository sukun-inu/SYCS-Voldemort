プライバシーポリシー

最終更新日：2026年5月9日

収集する情報

Discord サーバー設定

Bot の機能設定（通知チャンネル ID、ウェルカムメッセージ、リアクションロール設定など）をサーバーごとにサーバー内に保存します。これらの設定はサーバー管理者が入力・編集した情報です。

Discord ユーザー情報（認証時のみ）

Web 管理画面へのログイン時に、Discord OAuth2 を通じてユーザー ID・ユーザー名・アバターを一時的に取得します。これらはセッション管理にのみ使用し、永続的には保存しません。

メッセージ内容（一時処理のみ）

AI 会話機能や DJAudio-DL 機能の処理に必要なメッセージ内容を一時的に参照します。これらはデータベースに保存されることなく、処理完了後に破棄されます。AI 会話の文脈は直前のやりとりのみをメモリ上で保持します。

アクセスログ

Web 管理画面へのアクセスログ（IP アドレス、タイムスタンプ、操作内容）をサーバーのログファイルに記録する場合があります。これはセキュリティ監査および不正アクセスの調査を目的としています。

情報の利用目的

Bot 機能の提供

地震アラート・AI 会話・DJAudio-DL・ウェルカム通知などの Bot 機能を提供するために設定情報を使用します。

Web 管理画面の認証

Discord OAuth2 を通じた本人確認および管理者権限の検証のためにユーザー情報を使用します。

セキュリティの確保

不正アクセスの検知・防止およびシステムの安定稼働のためにアクセスログを利用します。

利用する第三者サービス

本 Bot は以下の外部サービスを利用しています。各サービスのプライバシーポリシーが適用されます。

Discord

Bot の動作基盤および OAuth2 認証に使用します。Discord のプライバシーポリシーが適用されます。

OpenAI / Groq

AI 会話機能（ヴォルデモート）の応答生成に使用します。送信されたメッセージは各社の API を経由します。各社のプライバシーポリシーが適用されます。

VirusTotal

DJAudio-DL 機能において投稿された URL のセキュリティチェックに使用します。URL が VirusTotal の API に送信されます。

P2PQuake

地震アラート機能において地震情報のリアルタイム受信に使用します。

MetalpriceAPI

貴金属価格の取得に使用します。

データの保管・削除

設定データの保管場所

サーバー設定情報はホスティングサーバー上のボリュームに保存されます。外部の第三者と共有されることはありません。

設定データの削除

Bot をサーバーから退出させると、そのサーバーに紐づく設定データは順次削除されます。また、Web 管理画面から各設定を個別に削除することもできます。

セッション情報

Web 管理画面のログインセッションはブラウザを閉じるか、ログアウト操作により終了します。

ポリシーの変更

更新について

本プライバシーポリシーは予告なく変更される場合があります。重要な変更がある場合はこのページにて告知します。定期的にご確認ください。
