プライバシーポリシー

最終更新日：2026年8月25日

{{ icon('info-circle-fill') }}はじめに

SYCS Voldemort（以下「本 Bot」）は、Discord 上で動作する多機能 Bot およびその Web 管理画面を提供するサービスです。 本プライバシーポリシーは、本サービスがどのような情報をどのような目的で取り扱うかを説明するものです。 本サービスをご利用いただくことで、本ポリシーの内容に同意したものとみなします。

{{ icon('database-fill') }}収集する情報

サーバー設定情報

Bot の機能を有効化するために、管理者が Web 管理画面またはスラッシュコマンドで入力した設定情報（通知チャンネル ID・ウェルカムメッセージ・リアクションロール設定・ニュースフィードキーワードなど）をサーバーごとに保存します。

Discord ユーザー情報（認証時のみ）

Web 管理画面へのログイン時に、Discord OAuth2 を通じてユーザー ID・ユーザー名・アバターハッシュを一時的に取得します。 これらはセッション管理にのみ使用し、データベース等への永続保存は行いません。ログアウトまたはセッション終了と同時に破棄されます。

監査ログ・ユーザー状態情報

サーバー運用の安全性確保およびトラブル調査のため、メンバーの参加/退出、BAN/KICK、タイムアウト、ロール変更、VC入退室などのイベントを保存します。 あわせて、ユーザーID・表示名・ロール情報・権限情報（例: 管理者権限の有無）・実行者情報（取得可能な場合）を記録することがあります。

メッセージ内容（一時処理のみ）

AI 会話・DJAudio-DL・セキュリティチェック機能の処理に必要なメッセージ内容を一時的に参照します。 これらは処理完了後に破棄され、データベースには保存されません。AI 会話の文脈はメモリ上で直前のやりとりのみ保持し、Bot の再起動でリセットされます。

音声録音データ（VC録音機能）

サーバー管理者が VC録音機能を有効にした場合、対象ボイスチャンネルの音声を参加者ごとに分けて記録します。 録音には発言内容そのものに加え、発言者の Discord ユーザー ID・表示名・発話時間が含まれます。 音声は個人を識別しうる情報であり、個人情報保護法上の個人情報に該当し得ます。

録音の開始時には、対象チャンネルに録音中である旨を必ず通知します。この通知を無効にすることはできません。 録音されたくない場合は、当該チャンネルから退出するか、/record exclude により自身を録音対象から除外できます。除外は進行中の録音にも直ちに反映されます。

アクセスログ

Web 管理画面へのアクセスログ（IP アドレス・タイムスタンプ・操作内容）をサーバーのログファイルに記録する場合があります。 これはセキュリティ監査および不正アクセスの調査を目的としています。

{{ icon('mic-fill') }}録音データの取り扱い

VC録音機能は、議事録として記録を残す用途、および法令に基づき政府機関・法的機関へ提供する必要が生じた場合の用途を想定して設計されています。

本サービスの運営者は、政府機関への提供が必要な場合を除き、録音データを一切使用いたしません。 内容の閲覧・分析・第三者への提供・学習データとしての利用は行いません。録音データが外部の AI サービス等へ送信されることもありません。

録音データは、当該サーバーの管理者が設定した保存期間（既定7日、最長30日）が経過した時点で自動的に削除されます。 ダウンロード用リンクは保存期間の経過とともに失効します。

録音機能を各サーバーでどのように使用するかは、その運用者の責任において、適用される法令に則って行ってください。 録音の実施にあたっては、参加者への事前の周知、必要な同意の取得、目的外利用の禁止、安全管理措置など、個人情報保護法その他の関係法令が定める義務が運用者に生じ得ます。 本サービスは録音の手段を提供するものであり、その運用が適法であることを保証するものではありません。

{{ icon('list-check') }}情報の利用目的

収集した情報は以下の目的にのみ使用します。

  • 地震アラート・AI 会話・DJAudio-DL・ウェルカム通知などの Bot 機能の提供
  • Discord OAuth2 を通じた本人確認および管理者権限の検証
  • 荒らし・不正行為への対応、監査記録の確認、問い合わせ対応
  • 不正アクセスの検知・防止およびシステムの安定稼働の確保
  • VC録音機能における、議事録の作成および法令に基づく提供への対応

収集した情報を上記以外の目的に使用することはありません。

とりわけ録音データについては、政府機関への提供が必要な場合を除き、運営者による使用を一切行いません。

{{ icon('boxes') }}利用する第三者サービス

本 Bot は以下の外部サービスの API を使用しています。各サービスへの情報送信は機能提供に必要な範囲に限られます。各サービスのプライバシーポリシーも合わせてご確認ください。

  • Discord — Bot の動作基盤および OAuth2 認証
  • OpenAI / Groq — AI 会話機能の応答生成。処理対象のメッセージが各社の API を経由します
  • VirusTotal — セキュリティ検知機能における投稿 URL・添付ファイルのスキャン
  • yt-dlp — DJAudio-DL 機能における音声ストリームの取得（ローカル処理）
  • P2PQuake — 地震アラート機能のリアルタイム地震情報受信
  • MetalpriceAPI — 貴金属価格データの取得
  • Google News RSS — ニュースフィード機能の記事取得

{{ icon('shield-fill-check') }}データの保管・削除

保管場所とアクセス

サーバー設定情報および監査データは、ホスティングサーバー上のストレージ/データベースに保存されます。外部の第三者と共有・販売されることはありません。

保持期間

監査データ（ユーザー状態履歴）は既定で最大10年間（3650日）保持され、保持期限を超えたデータは順次削除されます。 なお、法令・紛争対応・セキュリティ調査のために必要な場合は、合理的な範囲で保持期間を延長することがあります。

録音データはサーバーごとに設定された保存期間（既定7日、最長30日）で自動的に削除されます。監査データとは別の扱いで、10年保持の対象には含まれません。

削除方法

Web 管理画面から各設定を個別に削除することができます。Bot をサーバーから退出させた場合は、当該サーバーに紐づくデータを合理的期間内に削除または無効化します。

セッション情報

Web 管理画面のログインセッションは、ログアウト操作またはセッション終了により破棄されます。
