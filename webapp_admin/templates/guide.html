{{ icon('terminal-fill') }}誰でも使えるコマンド

{{ icon('music-note-beamed') }}DJAudio-DL 自動

管理者が設定した監視チャンネルに URL を貼るだけで MP3 ダウンロードリンクが送信されます。出力チャンネルを別途設定すると、リンクをそちらへ転送することもできます。

  1. 管理者が設定した監視チャンネルに URL を貼り付けます。
  2. Bot が ⏳ リアクションを付けて処理開始を知らせます。
  3. 変換完了後、✅ リアクションと共に期限付きダウンロードリンクを送信します（出力チャンネル設定時はそちらへ）。

対応サービス

YouTube / YouTube Music SoundCloud Bandcamp ニコニコ動画 TikTok 汎用直リンク Spotify 非対応 Apple Music 非対応 Amazon Music 非対応

{{ icon('soundwave') }}TTS 読み上げ自動

管理者が設定した読み上げチャンネルにメッセージを投稿すると、指定したVC で自動読み上げされます。VC に誰かが入ると Bot も自動参加し、全員退出で自動退出します。

  1. 管理者が Web 管理画面 → TTS 読み上げ で VC チャンネルと読み上げチャンネルを設定し、有効にします。
  2. 設定した読み上げチャンネルにメッセージを投稿するか、対象 VC に入室します。
  3. Bot が VC に自動参加し、メッセージを順番に読み上げます。

ユーザーコマンド

/voice set [voice] [rate]

自分の読み上げ声と速度（語/分）を設定します。声の選択肢はサーバーの TTS API に依存します。

/voice reset

自分の声設定をデフォルトに戻します。

/voice info

現在の自分の声設定を確認します。

/dict add [word] [reading]

読み替え辞書に単語を登録します。登録した単語は読み上げ時に指定の読みに置換されます。

/dict remove [word]

辞書から単語を削除します。

/dict list

現在登録されている辞書の一覧を表示します。

{{ icon('info-circle') }}読み上げのルール

URL は「URL」、メンションは「メンション」、カスタム絵文字は絵文字名に自動変換されます。 メッセージが字数制限を超えた場合は「以下省略」と読まれます（上限は管理者が設定）。

{{ icon('record-circle') }}VC録音開始は管理者のみ

管理者がボイスチャンネルの音声を参加者ごとの別トラックで録音できます。議事録を残したい場合や、法的機関へ提出する必要が生じた場合を想定した機能です。

{{ icon('bell-fill') }}録音は必ず通知されます

録音が始まると、対象のボイスチャンネルへ録音中である旨が必ず投稿されます。この通知を無効にすることはできません。黙って録るための機能ではありません。

録音されたくないとき

/record exclude

誰でも使えます。自分を録音の対象から外します。進行中の録音にもその場で反映され、あなたの音声はトラックに残りません。/record exclude exclude:False で対象に戻せます。

録音されたデータの扱い

  • 参加者ごとに別のトラック（mp3）へ分けて記録され、ZIP でまとめて配布されます。
  • ダウンロードリンクには期限があり（既定 7 日、最長 30 日）、過ぎると自動的に削除されます。
  • 各トラックは同じ時間軸に揃えられているため、途中から参加した人は冒頭が、途中で抜けた人は末尾が無音になります。
  • 運営者は、政府機関への提供が必要な場合を除き録音データを使用しません。

{{ icon('exclamation-triangle-fill') }}録音する側の責任

音声は個人情報保護法上の個人情報に該当し得ます。録音の実施・保管・提供は各サーバーの責任において、法令に則って行ってください。詳細はプライバシーポリシーをご確認ください。

{{ icon('chat-dots-fill') }}AI 会話（ヴォルデモート）自動

管理者が指定した応答チャンネルにメッセージを送るだけで Bot が返信します。応答チャンネルが未設定の場合、すべてのチャンネルで反応します。

  • 直前のやりとりを踏まえた連続した対話が可能です。
  • 日本語専用・ヴォルデモート卿のキャラクターで応答します。

{{ icon('activity') }}地震アラート自動

管理者が設定した通知チャンネルに地震情報をリアルタイムで通知します。

  • P2PQuake 連携 — WebSocket で日本全国の地震情報をリアルタイム受信します。
  • ビジュアル通知 — 震度バッジ画像・震度分布地図を Embed に添付して送信します。
  • EEW・津波対応 — 緊急地震速報（予報・警報）および津波予報にも対応しています。

{{ icon('stars') }}その他の自動機能

  • ウェルカム / グッバイ — メンバーの参加・退出時に設定したメッセージを自動送信します。
  • VC 通知 — ボイスチャンネルへの参加・退出・移動を通知します。退出時は通話時間も表示します。
  • スティッキーメッセージ — 新しいメッセージが投稿されるたびに固定メッセージを最下部に再掲します。
  • リアクションロール — 指定メッセージへのリアクションに連動してロールを自動付与・解除します。
  • Google News フィード — 設定したキーワードで Google News を定期検索し、新着記事を自動投稿します。

{{ icon('shield-fill-check') }}管理者向け設定要管理者権限

上記の自動機能はすべてサーバーの管理者が設定する必要があります。スラッシュコマンド（Discord 上）または Web 管理画面から設定できます。

{{ icon('display') }}Web 管理画面でできること

各機能の送信先チャンネルや通知条件の設定、DJAudio のキャッシュ・クールダウン調整、ニュースフィードのキーワード管理、リアクションロールの絵文字とロールの紐づけ管理、TTS の VC・読み上げチャンネル・声・辞書管理、セキュリティ設定（信頼済みユーザー・バイパスロール）、VC録音の開始・停止と保存期間の設定。

{{ icon('sliders') }}録音ミキサー

録り終えた録音は、管理画面の VC録音 から「ミキサー」を開くと、参加者ごとのトラックを同じ時間軸に並べて波形表示・再生できます。ミュート／ソロ／音量の調整と、波形をクリックしての頭出しに対応しています。
